## Agent skills

Issues and specs live as GitHub issues in `guihirsch/atesto`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

Five canonical triage labels, with label strings equal to their role names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the repo root and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
